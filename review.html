A structured, fair annual review — less paperwork, more honest conversation.

How it works

1
Reviewee fills in objectives + self-assessment~20–30 mins. Rate yourself and add context.
2
2 peers provide short written feedback~10 mins each via a shared link.
3
Manager completes assessment + sets targets~20–30 mins, building on the reviewee's input.
4
Meet, align, export the summaryOne-page output with actions to track all year.
